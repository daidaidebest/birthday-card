# 师宝宝的生日童话 · v18

**网址：<https://daidaidebest.github.io/birthday-card/>**

一部大约 3 分半钟的生日小电影（不含片尾字幕和她停留的时间）。讲故事的段落（沙画、旷野与星空）会自己往下走，旁边有一个很淡的“跳过”；需要她亲手完成的时刻会一直等着她：翻开信封、轻触金星、翻书、取下照片、打开信、点亮蜡烛、许愿和吹灭蜡烛。它是纯静态网页，不需要 WebGL，也不用安装任何依赖。每一个场景都是 2.5D 的。

## 故事顺序
0. **开场 · 一弯月牙**：按住月牙，它慢慢盈满，月光铺满屏幕，故事开始。
1. **序章 · 猫头鹰的信**：一段真正的三维镜头（Blender 建模、Cycles 渲染）：镜头像无人机一样从月亮下方滑向湖边悬崖上的古堡，远山、松林、湖上的薄雾和窗里的烛光都有真实的纵深。一只雪白的猫头鹰扇着翅膀从月亮前飞过，转头看了她一眼，带着信飞出画面。月亮下她可以用手指划过夜空，撒下一路星光。信封落下来，她把它翻过来，信封上系着一条豆沙粉的缎带，打着蝴蝶结；轻触蝴蝶结，结慢慢松开，缎带从两边滑落，信封打开，信纸滑出、展开，用绿墨水写出录取通知（开学日期：十一月三日）。
2. **第一章 · 只认识你**：同样是三维的书房：壁炉、书架、拱形窗外的月亮、灯串，镜头缓缓地呼吸。她亲手打开封面、拖动书页，最后点一下，走进书里。
3. **第二章 · 两条来路**：两块沙画灯箱跟着音乐（116 bpm，每两小节一站，大约 4 秒）自动播放她和你的路线，手指划过会在沙上留下痕迹，扫一下就提前走到下一站。最后合成一张中国地图，一道流金般的光慢慢扫过沙面；两条路在深圳相遇。
4. **第三章 · 藏起时光**：拍立得挂在虚化的书房里，可以取下任意一张，看进照片的景深里。之后是你写的那封生日信。
5. **第四章 · 风与星光**：两匹马在金色旷野上奔跑（按住屏幕一起跑）；然后是大草原：狮子就是原画本身，只让安全的地方动起来：呼吸、鬃毛被风吹动、母狮偶尔甩一下尾巴尖、耳朵轻轻一抖、眼睛慢慢眨一下，脸从不变形；草在风里起伏，鸟群飞过落日，夜色一层层落下。星星出来以后，由她用手指把它们一颗颗连起来（每连一颗响一个音，连完是一句旋律），连成一弯月牙以后，最亮的那颗落下来。
6. **终章 · 为你点亮**：三维的蛋糕（两层奶油蛋糕、糖做的玫瑰、珍珠和六支蜡烛）放在书房的圆桌上。落下的星星点亮第一支蜡烛，她把烛火带到其余五支上。许愿、吹灭蜡烛之后，房间安静下来，灯慢慢亮起，窗外远远地绽开香槟金色的烟花（轻点夜空可以自己放一朵，烟花踩着音乐的拍子绽开，每第五朵是一颗心），几片玫瑰花瓣和金色的光点缓缓飘落，两只小泰迪安静地陪着她，然后是最后一封信和片尾字幕。

**会跟着她动**：在电脑上，画面会微微朝鼠标方向偏；在手机上，倾斜手机就能“看进”画面。

**两只小泰迪**：它们会自己玩（汪一声、打喷嚏、追自己的尾巴、站起来作揖、满地撒欢、跑去找对方），会对故事里的声音竖起耳朵，偶尔说一句和这一章有关的话；摸摸它们会冒出爱心，点它们会跳、会转圈、会作揖，还会叼来一个小球陪她玩。它们会自动避开按钮和提示。

**贯穿全片的线索**：每一章都以一点金色的光结束，下一章从这点光里展开；同一段原创主旋律贯穿全片，《生日快乐》在序章、星空和终章里出现。

## 最常改的地方（不需要任何工具）
- **照片和书信**：在 `site/js/content.js` 里改。现在是 3 张 Unsplash 示意照片。照片放进 `site/assets/img/` 后，改对应的 `src`、`title`、`caption`。
  - 换成自己的照片后，照片会以柔和的推拉镜头展示。想要“活照片”的景深效果，再做一步（需要 Python）：
    `pip install onnxruntime opencv-python pillow numpy`（第一次运行会自动下载约 100 MB 的景深模型）
    → `python3 tools/depth.py site/assets/img/你的照片.webp`
    → `python3 tools/layers.py 你的照片 3`
    → `python3 tools/layers.py --manifest`
    → `tools/build.sh`
- **音乐**：每一章一首，在 `site/assets/audio/*.mp3`。全部由 `tools/score.py` 重新生成（原创作曲，用 MuseScore General 音色库里的钢琴、弦乐、吉他、钢片琴和八音盒演奏，需要 `fluidsynth` 和 `musescore-general-soundfont`），也可以用同名文件替换。

## 发布
推送到 `main` 分支后，仓库里的 `.github/workflows/pages.yml` 会依次执行 `npm ci → npm run lint → npm run build`，把 `site/` 复制到 `dist/` 并发布到 <https://daidaidebest.github.io/birthday-card/>，一两分钟后生效。部署完成后，工作流会用 `scripts/check-memory-book.mjs --url` 检查线上页面能否正常打开。所有路径都是相对路径。

本地预览：运行 `npm run dev`（或在 `site` 目录运行 `python3 -m http.server 8123`），然后打开 `http://localhost:8123`。加上 `?scene=film`（或 `book`、`journey`、`memories`、`wish`）可以直接从某一章开始。

## 画面是怎么做的
**v15：真正的三维场景。** 古堡、猫头鹰、书房和蛋糕现在是在 Blender 5.0.1 里搭出来的三维场景（脚本在 `tools/blender/`），用 Cycles 渲染：
- `castle.py`：悬崖、湖、松林、远山用高度场和程序化模型生成；古堡由塔楼、尖顶、大厅、城墙拼成，石墙、石板屋顶、崖壁用 Poly Haven 的 CC0 材质（`ph_fetch.py` 下载）；湖面有月光反射，湖上有体积雾，窗里的烛光逐帧闪烁。镜头沿一条缓动曲线从月亮下方飞到古堡前，最后 4 秒的慢漂移正放再倒放，接在信封打开的那段时间里循环。
- `owl.py`：雪鸮由身体、头、面盘、眼睛、尾羽和两段式翅膀组成，翅膀挂在骨骼上：下扑比上抬慢，上抬时翅尖收拢，身体随每次下扑微微上浮，长时间滑翔，转弯时侧倾，经过月亮时把头转向镜头。
- `study.py`：书房（壁炉和程序化火焰、整墙的书、拱形窗外的月亮和远处的塔、灯串、Poly Haven 的扶手椅、吊灯、油灯、镜子、座钟、植物和地毯）；同一个场景还渲染出终章的蛋糕：两层奶油蛋糕、裱花边、糖玫瑰、珍珠、金色蛋糕托和六支蜡烛，分“等待点亮”“烛光”“灯亮起来”三种光照，外加一张窗玻璃的遮罩（烟花只出现在玻璃后面）。烛芯在画面里的位置由脚本导出，网页把火焰画在这些点上。
- 渲染在阿里云的 A10 上进行（Kaggle 只用于 AI 视频）；书房的循环镜头走一个闭合的小椭圆，最后一秒溶进第一秒，没有接缝。

以下是 v12–v14 的做法（视频不能播放时仍然会用到这些画面）：
0. **会动的镜头**（v13–v14）：第四章奔跑的马和鼻尖相碰的特写、书房的循环镜头是短视频（书房用 `encode.py --pingpong 60` 把前 2.5 秒正放再倒放，接成没有接缝的循环）。先用 FLUX.1-schnell 画出关键帧（`tools/video/keyframes.py`），再用开源的 Wan2.2-TI2V-5B（Apache-2.0）在 Kaggle 的两张 T4 上把关键帧变成 5 秒的视频（`tools/video/i2v.py`，每张卡同时渲染一段），最后用 `tools/video/encode.py` 压成网页用的 H.264（`site/assets/video/`）。网页把视频画进画布里，光效和粒子仍然叠在上面；如果浏览器不允许自动播放（比如 iPhone 的低电量模式），会自动换回原来的 2.5D 手绘画面。
   开场（v14）不用视频：古堡和猫头鹰是 FLUX.1-schnell 生成的照片质感画面，古堡用景深拆层做航拍镜头，猫头鹰由 `tools/owl_glide.py` 按景深抠出来，在同一个镜头里滑翔。
1. **手绘关键画面**：古堡、猫头鹰、狮子、马的特写和蛋糕用开源的 FLUX.1-schnell（Apache-2.0）生成，在 Kaggle 的免费 GPU（两张 T4）上运行，脚本和提示词都在 `tools/keyart.py`（开场的古堡和猫头鹰用的是同一个模型在 Hugging Face 上的免费演示）。蛋糕从黑底上抠出，蜡烛不点燃，火焰由网页实时画在烛芯上。
2. **开场素材**：`tools/prologue_art.py` 处理古堡和猫头鹰：猫头鹰从黑底上抠出并在肩部拆开，让翅膀可以扇动。信封和信纸由 `tools/parchment.py` 画成做旧的羊皮纸，拆成口袋、封舌和内衬；深红色火漆由 `tools/seal_blender.py` 在 Blender 里渲染，单独一层，可以被按碎。
3. **夜色**：`tools/night.py` 把落日画面改成同一处的月夜（去掉太阳，换成月光色调，地平线留一线余晖）。两幅画逐像素对齐，所以可以用同一套景深层慢慢溶过去。
4. **书房**（v13）：温暖的书房同样用 FLUX.1-schnell 画成（横竖各一幅），`tools/study_lights.py` 找出画里的小灯泡、炉火、台灯和窗玻璃，网页让灯串闪烁、炉火呼吸，终章的天灯只出现在窗玻璃后面。蛋糕的蜡烛原来太长，`tools/cake_candles.py` 把每支蜡烛中间截掉一段再接好。
   （旧的奔跑的马：免费的 CC0 三维马模型（Quaternius）在 Blender 里渲染、用 `tools/creatures/` 重新上色，现在只在视频不能播放时使用。）
5. **离线算景深**：`tools/depth.py` 用开源的 Depth Anything V2（small，Apache-2.0）为每幅画估算一张景深图。
6. **拆成景深层**：`tools/layers.py` 按深度把画拆成 3–4 层。被前景挡住的部分用 OpenCV 修补，镜头移动时露出来的是合理的背景，而不是空洞或重影。层边缘按深度羽化，镜头静止时各层叠起来和原画完全一样。`--depth` 参数可以让夜景沿用白天那张画的景深。
7. **网页里实时合成**：`site/js/depth.js` 负责每一帧的视差、推拉镜头，以及跟随鼠标或手机倾斜。

## 改动代码时
- `site/js/` 里是可读的源码，网页实际加载的是打包好的 `site/js/gift.js`。改了源码后运行 `tools/build.sh` 重新打包（需要 Node.js）。
- 改了文字后，运行 `python3 tools/build_fonts.py` 重新生成字体子集。
- `tools/score.py` 重新生成全部配乐和新的音效（`python3 tools/score.py`，或 `python3 tools/score.py finale sfx`）；`tools/music.py` 是旧的合成器，仍然生成其余音效；`tools/parchment.py` 可以重新渲染羊皮纸信封和信纸，`tools/seal_blender.py` 用 Blender 渲染火漆；`tools/moon.py` 生成开场的月亮。

## v18 相比 v17
- **开场的月亮**：不再是星盘一样的刻度表盘，而是一片月下的湖：紫罗兰到玫瑰色的天空、慢慢飘过的被月光照亮的云、远处湖岸上亮着烛光的小城堡、湖面上颤动的月光小路和窗灯的倒影、缓缓升起的萤火虫；月亮暗的一半是透明的，只剩一点地照的轮廓；按住月亮时，一圈细细的光环慢慢填满。
- **整体更亮**：古堡影片重新调色（结尾画面平均亮度从 39 提到 63，岩壁的纹理看得见了，仍然是月夜），书房影片提亮了中间调；拆信时古堡、照片背后的书房、蛋糕房间里那层变暗的遮罩都减轻了。
- **更清楚**：模糊主要不是因为模型不够细，而是视频压得太狠（CRF 23–24）、降噪和运动模糊，以及手机上画面被再放大一次。现在古堡影片用 CRF 20、循环镜头用 CRF 22，都加了锐化。
- **猫头鹰**：身体收窄、肚子变平、绒毛变短，飞起来更修长；只重新渲染了它出现的那些帧，再拼回原来的影片。
- **狮子**：不再用 AI 生成的视频（母狮转头时脸会变形），回到干净的原画，只让鬃毛、尾巴、耳朵、呼吸和眨眼动起来（`site/assets/img/lion-rig.png` 是只在这些地方为非零的权重图）。
- **拆信**：金色小星星换成一条缎带和蝴蝶结。
- **会和画面一起动的配乐**（`tools/score.py` → `site/js/score-map.js`、`site/js/audio.js`）：每章的音乐分成两三层（伴奏、旋律，马奔跑时还有一层鼓点，跟着她跑得多快）；换章节时不再交叉淡化，而是在下一个乐句或小节线上，用这一章自己写好的终止式收住，下一章正好从解决的和弦进来；书房的开头会一直停在壁炉的段落，直到她翻开封面，马的段落一直跑到它们相遇。每一个动作都会在当下的和弦里、踩着下一个拍点响一个音：划过夜空的星光、猫头鹰、信封落下和打开、翻开封面、每一页、沙画换站、取下照片、翻到照片背面、读信、两匹马相遇、她连起的每一颗星、星星落下、每一支蜡烛（六支蜡烛连起来是主题的一句）、许愿、她放的烟花、盖邮戳；最后的星空镜头里，片尾曲在自己的最后一个和弦上结束。
- **更多可以亲手做的事**：划过夜空撒星光；在照片上再点一下，翻到背面看手写的一句话（`content.js` 里每张照片的 `back`）；自己把星星连成月牙；吹完蜡烛后点夜空放烟花。
- 旧的整首配乐文件（`prologue.mp3` 等）已经删掉，现在用的是分层的 `*.bed.mp3`、`*.lead.mp3`、`film.pulse.mp3`、每章的终止式 `*.end.mp3`、片尾曲的 `finale.head/outro.mp3` 和一个音色库 `stingers.mp3`。

## v17 相比 v16
- **手机上读书**：书页按阅读时的大小排版，书打开后镜头先看到整本摊开的书，再慢慢推近，让正在读的那一页占满屏幕宽度的大约 88%，左边留一点书脊和左页的影子。
- **翻页是一整张纸**：翻起的书页先从边角抬起，在空中弯成一道弧，再落到左页上；纸面的明暗随角度连续变化，抬起的纸在下面的页面上投下移动的影子；手机上翻页时镜头会轻轻退后一点，让整张纸都在画面里。不再出现半张纸突然消失的情况。书页右下角会轻轻翘起，提示可以翻。
- **由她来完成**：信封、金星、封面、每一页、照片、信、五支蜡烛、许愿和吹蜡烛都等她亲手来做，不会自己完成；故事段落可以自己播放，并有“继续”或很淡的“跳过”。测试用的自动播放只在网址加 `?auto`（或 `?autostart`）时出现。
- **章节之间**：书页在镜头里碎成流沙，变成下一章的沙画；落下的星星不跟着画面消失，房间在它周围亮起来，它继续飞去点亮第一支蜡烛；其他章节的金光带着下一章的颜色，照片一章的小灯从两条路相遇的地方向两边亮起；信上的墨迹化成暖色的光点飘起。
