# 写给师宝宝的一场梦 · v12

**网址：<https://daidaidebest.github.io/birthday-card/>**

一部大约 3 分半钟的生日小电影（不含片尾字幕和她停留的时间）。它会自己往下走，但每一章都可以亲手参与：翻书、在沙里划过、取下照片、和野马一起奔跑、把烛火一支支传过去。它是纯静态网页，不需要 WebGL，也不用安装任何依赖。每一个场景都是 2.5D 的。

## 故事顺序
0. **开场 · 一弯月牙**：在金色细线的星盘中心，按住月牙，它会慢慢盈满，月光铺满屏幕，故事开始。
1. **序章 · 月光来信**：月夜湖面上，一点光从月亮落下，化成一封系着香槟色丝带的信。她亲手解开丝带（点一下金色月牙扣，或者把丝带拖开），信纸升起，自己写字。
2. **第一章 · 只认识你**：书房被拆成四个景深层，漂浮的蜡烛各在自己的深度上。她亲手打开封面、拖动书页，最后点一下，走进书里。
3. **第二章 · 两条来路**：两块沙画灯箱同时播放她和你的路线，手指划过会在沙上留下痕迹，扫一下就倒出下一站。最后合成一张中国和日本的地图：两条路都经过深圳，一起走到日本东京，在那里刻出一颗心。
4. **第三章 · 藏起时光**：灯串上挂着三张拍立得，可以取下任意一张，看进照片的景深里。之后是你写的那封生日信。
5. **第四章 · 风与星光**：手绘风格的金色旷野上，一匹鹿皮色的公马和一匹花斑母马在奔跑。按住屏幕就和它们一起跑，轻点一下它们会跃起；跑过旷野，它们放慢脚步，镜头溶进一幅两匹马鼻尖相碰的特写。然后是大草原：两只狮子依偎在巨岩上，落日一层一层地沉成夜色，星星连成一颗心，最亮的那颗落下来。
6. **终章 · 为你点亮**：书房桌上一个手绘的两层蛋糕。落下的星星点亮第一支蜡烛，她把烛火带到其余五支上（或点一下蜡烛，让星光飞过去），每一支都有一句话。许愿、吹灭蜡烛（也可以对着麦克风吹），天灯升起，最后一封信和片尾字幕。

**会跟着她动**：在电脑上，画面会微微朝鼠标方向偏；在手机上，倾斜手机就能“看进”画面（iPhone 按住月牙时会请求一次“动作与方向”权限）。如果系统开启了“减少动态效果”，就不会跟随。

## 最常改的地方（不需要任何工具）
- **照片和书信**：在 `site/js/content.js` 里改。现在是 3 张 Unsplash 示意照片。照片放进 `site/assets/img/` 后，改对应的 `src`、`title`、`caption`。
  - 换成自己的照片后，照片会以柔和的推拉镜头展示。想要“活照片”的景深效果，再做一步（需要 Python）：
    `pip install onnxruntime opencv-python pillow numpy`（第一次运行会自动下载约 100 MB 的景深模型）
    → `python3 tools/depth.py site/assets/img/你的照片.webp`
    → `python3 tools/layers.py 你的照片 3`
    → `python3 tools/layers.py --manifest`
    → `tools/build.sh`
- **音乐**：每一章一首，在 `site/assets/audio/*.mp3`。用同名文件替换即可。

## 发布
推送到 `main` 分支后，仓库里的 `.github/workflows/pages.yml` 会依次执行 `npm ci → npm run lint → npm run build`，把 `site/` 复制到 `dist/` 并发布到 <https://daidaidebest.github.io/birthday-card/>，一两分钟后生效。部署完成后，工作流会用 `scripts/check-memory-book.mjs --url` 检查线上页面能否正常打开。所有路径都是相对路径。

本地预览：运行 `npm run dev`（或在 `site` 目录运行 `python3 -m http.server 8123`），然后打开 `http://localhost:8123`。加上 `?scene=film`（或 `book`、`journey`、`memories`、`wish`）可以直接从某一章开始。

## 画面是怎么做的
1. **手绘关键画面**：狮子、马的特写和蛋糕用开源的 FLUX.1-schnell（Apache-2.0）生成，在 Kaggle 的免费 GPU（两张 T4）上运行，脚本和提示词都在 `tools/keyart.py`。蛋糕从黑底上抠出，蜡烛不点燃，火焰由网页实时画在烛芯上。
2. **夜色**：`tools/night.py` 把落日画面改成同一处的月夜（去掉太阳，换成月光色调，地平线留一线余晖）。两幅画逐像素对齐，所以可以用同一套景深层慢慢溶过去。
3. **奔跑的马**：免费的 CC0 三维马模型（Quaternius）在 Blender 里渲染，再用 `tools/creatures/` 里的脚本重新上色成手绘风格。
4. **离线算景深**：`tools/depth.py` 用开源的 Depth Anything V2（small，Apache-2.0）为每幅画估算一张景深图。
5. **拆成景深层**：`tools/layers.py` 按深度把画拆成 3–4 层。被前景挡住的部分用 OpenCV 修补，镜头移动时露出来的是合理的背景，而不是空洞或重影。层边缘按深度羽化，镜头静止时各层叠起来和原画完全一样。`--depth` 参数可以让夜景沿用白天那张画的景深。
6. **网页里实时合成**：`site/js/depth.js` 负责每一帧的视差、推拉镜头，以及跟随鼠标或手机倾斜。

## 改动代码时
- `site/js/` 里是可读的源码，网页实际加载的是打包好的 `site/js/gift.js`。改了源码后运行 `tools/build.sh` 重新打包（需要 Node.js）。
- 改了文字后，运行 `python3 tools/build_fonts.py` 重新生成字体子集。
- `tools/music.py` 可以重新合成全部配乐和音效；`tools/paper.py` 可以重新渲染信纸和信封；`tools/moon.py` 生成开场的月亮。

## 小提示
- 第一次打开需要按住月牙（浏览器要求先点击才能播放声音）。
- 右上角可以静音、暂停、跳到任意章节。按空格键暂停；读信时点“收好这封信”继续。
- 署名与版权：
  - 字体：Noto Serif SC（SIL OFL 1.1）、TeX Gyre Pagella / Chorus（GUST Font License）。
  - 地图轮廓来自 Natural Earth（公有领域）；开场的月亮取自 NASA 的公有领域月面影像。
  - 手绘画面由 FLUX.1-schnell（Apache-2.0）生成；三维马模型来自 Quaternius（CC0）。
  - 景深模型为 Depth Anything V2 Small（Apache-2.0），只在制作时离线使用，不随网页发布。
  - 配乐与音效为原创合成；《Happy Birthday to You》旋律属于公有领域。
  - 电影章节是原创画面，只在气氛上致敬《小马王》《狮子王》。

## v12 相比 v11
- 全部场景改为 2.5D：景深分层、视差、推拉镜头，并跟随鼠标或手机倾斜。
- 每一章都能亲手参与，不再只是看：开场按住月牙，解开信的丝带，翻书，在沙上划过，取下照片，和野马一起奔跑，把烛火一支支传过去。
- 火漆印章换成了月牙星盘和丝带金扣；章节之间改成柔和的焦点转换。
- 第四章：黑色剪影换成手绘画面，有奔跑的马、鼻尖相碰的特写，以及从落日溶进星夜的狮子。
- 终章的蛋糕换成手绘的两层玫瑰蛋糕，六支蜡烛由她亲手点亮；修复了“再许一个愿”之后停不下来的问题。
- 两只泰迪改用新的骨骼动画：腿会弯、耳朵和尾巴会动，会看着手指，被摸时会闭眼。
- 整体时长从约 4.5 分钟缩短到约 3 分半钟：到吹蜡烛约 3 分钟，之后是约半分钟的告白，然后是片尾字幕。
- 沿用了仓库里 10 月 8 日的修改：沙画旅程的终点改为日本东京（地图加上日本，两条路从深圳继续走到东京）。
