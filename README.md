# 师宝宝的生日童话 · v15

**网址：<https://daidaidebest.github.io/birthday-card/>**

一部大约 3 分半钟的生日小电影（不含片尾字幕和她停留的时间）。它会自己往下走，但每一章都可以亲手参与：翻书、在沙里划过、取下照片、和野马一起奔跑、把烛火一支支传过去。它是纯静态网页，不需要 WebGL，也不用安装任何依赖。每一个场景都是 2.5D 的。

## 故事顺序
0. **开场 · 一弯月牙**：在金色细线的星盘中心，按住月牙，它会慢慢盈满，月光铺满屏幕，故事开始。
1. **序章 · 猫头鹰的信**（向《哈利·波特》电影致敬的原创画面）：一张照片质感的古堡夜景被拆成五个景深层，镜头像航拍一样从月亮下方缓缓向前、向下滑向湖边悬崖上的古堡，近处的松林、悬崖、古堡和远山各自以不同的速度移动，窗里的烛光摇曳，薄雾流过。一只雪白的猫头鹰从月亮前安静地滑翔而过，飞出画面时松开了信；厚厚的羊皮纸信封翻转着落下来。她按下火漆：金光从裂缝里透出，火漆碎开，叠成三折的信纸滑出、展开，用绿墨水写出录取通知，这时配乐里第一次响起《生日快乐》的旋律。
2. **第一章 · 只认识你**：一间温暖的书房：一段真正拍出来的循环镜头（视频），镜头缓缓推近又退回，炉火跳动、灯串闪烁、茶杯冒着热气、窗外一轮满月；视频不能播放时换成五个景深层的 2.5D 画面。她亲手打开封面、拖动书页，最后点一下，走进书里。
3. **第二章 · 两条来路**：两块沙画灯箱跟着音乐（一首轻快的圆舞曲）自动播放她和你的路线，大约每 5 秒换一站，两块灯箱同时换。换站时镜头像走路一样平移过去：旧城市滑出画面，下一座城市从另一边走进来，前面的沙丘比远处的建筑移动得快一些。手指划过会在沙上留下痕迹，扫一下就提前走到下一站（仍然落在拍子上）。最后合成一张中国和日本的地图：两条路都经过深圳，一起走到日本东京，在那里刻出一颗心。
4. **第三章 · 藏起时光**：拍立得挂在书房的灯串上（身后是虚化的炉火和灯光），可以取下任意一张，看进照片的景深里。之后是你写的那封生日信。
5. **第四章 · 风与星光**：一段手绘动画风格的影片：一匹鹿皮色、黑鬃毛的公马和一匹花斑母马在金色旷野上奔跑。按住屏幕就和它们一起全速奔跑，松开时画面放慢成慢镜头；跑过旷野，镜头溶进两匹马鼻尖相碰的特写。然后是大草原：两只狮子依偎在巨岩上，落日一层一层地沉成夜色，星星连成一颗心，最亮的那颗落下来。
6. **终章 · 为你点亮**：温暖的书房里，桌上一个手绘的两层蛋糕（蜡烛是正常生日蜡烛的高度）。落下的星星点亮第一支蜡烛，她把烛火带到其余五支上（或点一下蜡烛，让星光飞过去），每一支都有一句话。许愿、吹灭蜡烛（也可以对着麦克风吹），吹灭蜡烛时落下一阵金色和粉色的彩纸，窗外升起天灯，最后一封信和片尾字幕。

**会跟着她动**：在电脑上，画面会微微朝鼠标方向偏；在手机上，倾斜手机就能“看进”画面（iPhone 按住月牙时会请求一次“动作与方向”权限）。如果系统开启了“减少动态效果”，就不会跟随。

**贯穿全片的线索**：每一章都以一点金色的光结束（信、书页、东京的那颗心、收好的信、落下的星星），下一章从这点光里慢慢展开。《生日快乐》的旋律在每一章的配乐里以不同的乐器出现（序章的钢片琴、书房的八音盒、沙画的钢琴、星空下的钢片琴，最后是蛋糕和片尾）。每章开头的章节卡下面有六支小蜡烛，每一章多点亮一支，一直通向蛋糕上的六支蜡烛。

## 最常改的地方（不需要任何工具）
- **照片和书信**：在 `site/js/content.js` 里改。现在是 3 张 Unsplash 示意照片。照片放进 `site/assets/img/` 后，改对应的 `src`、`title`、`caption`。
  - 换成自己的照片后，照片会以柔和的推拉镜头展示。想要“活照片”的景深效果，再做一步（需要 Python）：
    `pip install onnxruntime opencv-python pillow numpy`（第一次运行会自动下载约 100 MB 的景深模型）
    → `python3 tools/depth.py site/assets/img/你的照片.webp`
    → `python3 tools/layers.py 你的照片 3`
    → `python3 tools/layers.py --manifest`
    → `tools/build.sh`
- **音乐**：每一章一首，在 `site/assets/audio/*.mp3`。用同名文件替换即可。

## 发布
推送到 `main` 分支后，仓库里的 `.github/workflows/pages.yml` 会依次执行 `npm ci → npm run lint → npm run build`，把 `site/` 复制到 `dist/` 并发布到 <https://daidaidebest.github.io/birthday-card/>，一两分钟后生效。部署完成后，工作流会用 `scripts/check-memory-book.mjs --url` 检查线上页面能否正常打开。所有路径都是相对路径。

本地预览：运行 `npm run dev`（或在 `site` 目录运行 `python3 -m http.server 8123`），然后打开 `http://localhost:8123`。加上 `?scene=film`（或 `book`、`journey`、`memories`、`wish`）可以直接从某一章开始。

## 画面是怎么做的
0. **会动的镜头**（v13–v14）：第四章奔跑的马和鼻尖相碰的特写、书房的循环镜头是短视频（书房用 `encode.py --pingpong 60` 把前 2.5 秒正放再倒放，接成没有接缝的循环）。先用 FLUX.1-schnell 画出关键帧（`tools/video/keyframes.py`），再用开源的 Wan2.2-TI2V-5B（Apache-2.0）在 Kaggle 的两张 T4 上把关键帧变成 5 秒的视频（`tools/video/i2v.py`，每张卡同时渲染一段），最后用 `tools/video/encode.py` 压成网页用的 H.264（`site/assets/video/`）。网页把视频画进画布里，光效和粒子仍然叠在上面；如果浏览器不允许自动播放（比如 iPhone 的低电量模式），会自动换回原来的 2.5D 手绘画面。
   开场（v14）不用视频：古堡和猫头鹰是 FLUX.1-schnell 生成的照片质感画面，古堡用景深拆层做航拍镜头，猫头鹰由 `tools/owl_glide.py` 按景深抠出来，在同一个镜头里滑翔。
1. **手绘关键画面**：古堡、猫头鹰、狮子、马的特写和蛋糕用开源的 FLUX.1-schnell（Apache-2.0）生成，在 Kaggle 的免费 GPU（两张 T4）上运行，脚本和提示词都在 `tools/keyart.py`（开场的古堡和猫头鹰用的是同一个模型在 Hugging Face 上的免费演示）。蛋糕从黑底上抠出，蜡烛不点燃，火焰由网页实时画在烛芯上。
2. **开场素材**：`tools/prologue_art.py` 处理古堡和猫头鹰：猫头鹰从黑底上抠出并在肩部拆开，让翅膀可以扇动。信封和信纸由 `tools/parchment.py` 画成做旧的羊皮纸，拆成口袋、封舌和内衬；深红色火漆由 `tools/seal_blender.py` 在 Blender 里渲染，单独一层，可以被按碎。
3. **夜色**：`tools/night.py` 把落日画面改成同一处的月夜（去掉太阳，换成月光色调，地平线留一线余晖）。两幅画逐像素对齐，所以可以用同一套景深层慢慢溶过去。
4. **书房**（v13）：温暖的书房同样用 FLUX.1-schnell 画成（横竖各一幅），`tools/study_lights.py` 找出画里的小灯泡、炉火、台灯和窗玻璃，网页让灯串闪烁、炉火呼吸，终章的天灯只出现在窗玻璃后面。蛋糕的蜡烛原来太长，`tools/cake_candles.py` 把每支蜡烛中间截掉一段再接好。
   （旧的奔跑的马：免费的 CC0 三维马模型（Quaternius）在 Blender 里渲染、用 `tools/creatures/` 重新上色，现在只在视频不能播放时使用。）
5. **离线算景深**：`tools/depth.py` 用开源的 Depth Anything V2（small，Apache-2.0）为每幅画估算一张景深图。
6. **拆成景深层**：`tools/layers.py` 按深度把画拆成 3–4 层。被前景挡住的部分用 OpenCV 修补，镜头移动时露出来的是合理的背景，而不是空洞或重影。层边缘按深度羽化，镜头静止时各层叠起来和原画完全一样。`--depth` 参数可以让夜景沿用白天那张画的景深。
7. **网页里实时合成**：`site/js/depth.js` 负责每一帧的视差、推拉镜头，以及跟随鼠标或手机倾斜。

## 改动代码时
- `site/js/` 里是可读的源码，网页实际加载的是打包好的 `site/js/gift.js`。改了源码后运行 `tools/build.sh` 重新打包（需要 Node.js）。
- 改了文字后，运行 `python3 tools/build_fonts.py` 重新生成字体子集。
- `tools/music.py` 可以重新合成全部配乐和音效；`tools/parchment.py` 可以重新渲染羊皮纸信封和信纸，`tools/seal_blender.py` 用 Blender 渲染火漆；`tools/moon.py` 生成开场的月亮。

## 小提示
- 第一次打开需要按住月牙（浏览器要求先点击才能播放声音）。
- 右上角可以静音、暂停、跳到任意章节。按空格键暂停；读信时点“收好这封信”继续。
- 署名与版权：
  - 字体：Noto Serif SC（SIL OFL 1.1）、TeX Gyre Pagella / Chorus（GUST Font License）。
  - 地图轮廓来自 Natural Earth（公有领域）；开场的月亮取自 NASA 的公有领域月面影像。
  - 手绘画面由 FLUX.1-schnell（Apache-2.0）生成；三维马模型来自 Quaternius（CC0）。
  - 景深模型为 Depth Anything V2 Small（Apache-2.0），视频由 Wan2.2-TI2V-5B（Apache-2.0）生成，都只在制作时离线使用，不随网页发布。
  - 配乐与音效为原创合成；《Happy Birthday to You》旋律属于公有领域。
  - 开场与电影章节都是原创画面，只在气氛和画风上致敬《哈利·波特》《小马王》《狮子王》，没有使用电影中的画面、角色设计、标志或配乐。

## v14 相比 v13
- 开场：古堡换成照片质感的画面，拆成五个景深层，做成真正有纵深的航拍滑翔镜头；猫头鹰不再冲向镜头，而是从月亮前安静地滑翔而过。
- 整体：章节之间统一用“金色的光”过渡，上一章结束的那点光就是下一章开始的地方；《生日快乐》的旋律贯穿每一章的配乐；章节卡下面的小蜡烛一章一章点亮；吹蜡烛时落下彩纸。
- 书房：书房和蛋糕的场景换成真正会动的视频循环（镜头缓缓推近又退回，炉火和灯光在动）；视频不能播放时是五个景深层的画面，有跳动的炉火光和茶杯的热气。章节标题有柔和的底色，不再和书的封面叠在一起。
- 第二章：配乐换成更轻快的圆舞曲，沙画换站更快（约 5 秒一站）。
- 第三章：照片挂在虚化的书房里，不再是一片紫色的背景。
- 节奏：没人操作时，各章自动往下走的等待时间缩短；书里的字写得更快。
- 终章：蛋糕放在壁炉前、窗户下；窗外的天灯更清晰。

## v13 相比 v12
- 开场：古堡和猫头鹰从平面贴图换成真正会动的镜头；配乐换成温暖的 D 大调圆舞曲，去掉了容易吓人的低沉小调和猫头鹰叫声。
- 拆信：信纸不再穿过信封；火漆先透出金光的裂纹，再碎成几块飞散；信纸叠成三折滑出来，再一折一折展开。
- 第一章：去掉了身后漂浮的蜡烛，换成温暖的书房（壁炉、台灯、闪烁的小灯串、柔和的光斑）。
- 第二章：沙画跟着音乐自动播放，两块灯箱同时换站；换站从生硬的切换改成走路一样的平移。
- 第四章：奔跑的马和特写换成手绘动画风格的视频，按住屏幕全速奔跑，松开变成慢镜头（不再有点按跳跃）。
- 终章：蛋糕在新的书房里，蜡烛缩短到正常高度，天灯从窗外升起。
- 小狗被点、被摸时不再闭眼。

## v12 相比 v11
- 全部场景改为 2.5D：景深分层、视差、推拉镜头，并跟随鼠标或手机倾斜。
- 每一章都能亲手参与，不再只是看：开场按住月牙，解开信的丝带，翻书，在沙上划过，取下照片，和野马一起奔跑，把烛火一支支传过去。
- 开场改成向《哈利·波特》电影致敬的原创动画：云中俯冲、古堡、猫头鹰送信、立体翻转的羊皮纸信封和可以按碎的火漆；章节之间改成柔和的焦点转换。
- 第四章：黑色剪影换成手绘画面，有奔跑的马、鼻尖相碰的特写，以及从落日溶进星夜的狮子。
- 终章的蛋糕换成手绘的两层玫瑰蛋糕，六支蜡烛由她亲手点亮；修复了“再许一个愿”之后停不下来的问题。
- 两只泰迪改用新的骨骼动画：腿会弯、耳朵和尾巴会动，会看着手指。
- 整体时长从约 4.5 分钟缩短到约 3 分半钟：到吹蜡烛约 3 分钟，之后是约半分钟的告白，然后是片尾字幕。
- 沿用了仓库里 10 月 8 日的修改：沙画旅程的终点改为日本东京（地图加上日本，两条路从深圳继续走到东京）。
